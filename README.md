## About

A console portal in Python where students can ask for advice, comfort or motivation without showing their name, like a message in a bottle.

* Throw a bottle (your message) into the sea
* Catch a random bottle and reply to it, or throw it back
* Mark replies as helpful; the most helpful people become Lighthouses
* Report bad replies
* Search bottles and generate a report
* Everyone only sees random names like "Silver Anchor 42"

## How to run

Open `Anonymous\_Support\_Portal.ipynb` in Jupyter and run all cells, or run:

```
python portal.py
```

No extra libraries are needed. Demo accounts: **ayesha / 1234** and **bilal / 1234**.

## Files

* `Anonymous\_Support\_Portal.ipynb` - the code with explanations and tests
* `portal.py` - the same code as one Python file
* `portal\_data.json` - all the saved data (made when the portal runs)
* `activity\_log.txt` - a log of everything that happens
* `portal\_report.txt` - the latest report
